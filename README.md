# NEXA — Electronics Gadgets Discovery & Exploration Platform

Premium responsive single-page HTML website for the category:
**Electronics Gadgets Discovery & Exploration Platform**.

## Included
- 12 compact sections
- Responsive at 360px / 768px / 1440px / 1920px
- Centered headings, descriptions and buttons across desktop, tablet and mobile
- Right-to-left and left-to-right content rails
- Waterfall card reveals
- 360-degree CSS product viewer
- Live-style radar/trend tracker
- Interactive-style gadget map
- Scroll reveals, parallax-like depth, hover motion and clipping transitions
- Inline SVG logo and favicon
- No frameworks required
- GitHub Pages ready: upload `index.html` and open the page

## Images
The page uses verified, public-domain/free-commercial-use gadget photography hosted by Hippopx. The direct image URLs are kept in `index.html` so the project stays a lightweight single-file deployment.
